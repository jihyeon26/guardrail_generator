# Independent Implementation Boundary

This repository is developed as an independent public implementation.

## Allowed inputs

- official Python, Pydantic, LangChain, LangGraph, Microsoft Azure, PyPA, and NIST docs;
- peer-reviewed or otherwise publicly accessible research;
- public standards and documents whose licenses permit the intended use;
- synthetic SOPs, examples, expected outputs, and evaluation fixtures created here;
- general programming knowledge and publicly established design patterns.

## Disallowed inputs

- source code or Git history from private team or client repositories;
- private prompts, schemas, architecture diagrams, test cases, data, logs, screenshots,
  configuration, endpoints, identifiers, metrics, or model outputs;
- client names, branding, business rules, thresholds, or non-public problem details;
- close transcription from memory of non-public implementation details.

## Contributor checklist

Before each contribution, confirm that:

1. the change was created from this public specification and allowed public sources;
2. all example content is synthetic or has a recorded compatible license;
3. no private code, text, identifier, endpoint, credential, or history was copied;
4. third-party code and assets retain required notices;
5. any uncertain item is withheld until its rights and provenance are resolved.

Passing automated scanners does not establish intellectual-property clearance. This
document records the project boundary; it is not a legal determination.
